# Coding Style

Language

Shell (zsh)

---

Function Naming

snake_case

---

Variables

lowercase

---

Constants

UPPER_CASE

---

Indentation

4 spaces

---

Quotes

Prefer double quotes.

---

Always use:

local

inside functions.

---

Never use global variables.

---

Every file begins with:

- Purpose
- Author
- Date

---

Every function requires:

- Description
- Parameters
- Return
- Example

---

No duplicated logic.
